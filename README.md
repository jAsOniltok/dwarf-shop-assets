# dwarf-shop-assets

Static files for a small web toy, served through jsDelivr.

- `dwarf/ph/*.glb`, `dwarf/tex/*.webp` — models and textures from [Poly Haven](https://polyhaven.com), CC0 1.0 (optimized: meshopt, webp).
- `dwarf/models/*.glb` — [Kenney Furniture Kit](https://kenney.nl), CC0 1.0 (`licenses/kenney-furniture-kit.txt`).
- `dwarf/dist/chunk-*.js` — minified bundle of [three.js](https://threejs.org) (MIT, `licenses/three.txt`) and [Rapier](https://rapier.rs) (Apache-2.0, `licenses/rapier.txt`).
- `dwarf/dist/rapier-*.wasm` — Rapier physics engine (Apache-2.0).
